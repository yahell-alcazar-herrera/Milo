Política de Privacidad

Última actualización: 22 de septiembre de 2026

Esta página explica qué datos recoge Milo cuando lo usás, y qué hacemos con ellos.

1. Qué datos se recogen

  • Para crear una cuenta se guarda tu correo y una representación cifrada de tu contraseña. La contraseña original no se guarda.
  • Los mensajes se envían al servidor de Milo, que los remite a Groq para generar la respuesta. La API key permanece en el servidor y no se envía al navegador.
  • El historial de conversación se mantiene en la sesión del navegador mientras chateás y no se guarda como historial permanente en la base local de cuentas.

2. Sesión y almacenamiento local

El navegador guarda la aceptación de los términos. La sesión de acceso usa una cookie protegida para mantener tu cuenta iniciada. No guardes API keys en el navegador.

3. Terceros involucrados

Cuando el chat necesita generar una respuesta con IA, el mensaje se envía a Groq Inc., sujeto también a sus propias políticas. Te recomendamos revisarlas si te preocupa el manejo de esos datos.

4. Menores de edad

Este sitio no está dirigido a menores de [18] años sin supervisión de un adulto responsable.

5. Tus derechos

Podés dejar de usar el sitio en cualquier momento y borrar los datos guardados localmente desde tu navegador. Para eliminar una cuenta o hacer consultas, contactá al responsable del proyecto.

6. Cambios a esta política

Cualquier cambio importante se reflejará en esta misma página con su fecha de actualización.
